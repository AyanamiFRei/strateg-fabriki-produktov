# Интервью и модельные респонденты (опция)

**Знания:** `kb/methods/A-framing-discovery.md` (A1 JTBD, A3 Mom Test), `kb/methods/B-evidence.md` (B3).

## Реальные интервью
1. Гайд `interviews/guide.md`: восстановление последнего реального случая (когда, что делали, чем заменяли, сколько стоило),
   без вопросов «купили бы вы»; 5–7 вопросов; цель — проверить конкретные [H]/[A].
2. Согласие: шаблон `agent/templates/consent.md`; без согласия интервью не проводятся. В репозиторий — только обезличенные
   расшифровки (имена → «Р1, Р2»; без телефонов, адресов, ФИО).
3. Расшифровку регистрируй `source add --file interviews/r1.txt --reliability medium`; факты — цитатами, как обычно.
   Одно интервью — не распространённость: формулируй «у Р1 было…», не «клиенты хотят».

## Модельные респонденты (синтетика)
1. Роли — из сегментов situation.md (например «организатор семьи», «скептик», «пожилой участник»). Субагент `respondent`
   (или отдельный проход по `agent/roles/respondent.md`); ≤3 прогона, перестановка порядка вопросов.
2. Выход — только: новые гипотезы [H], возражения, формулировки для проверки, вопросы для реальных интервью.
   Записывай `kind:"synthetic"` со связью `supports` → H; **без процентов и счёта людей** (код 2).
3. В документах синтетика живёт только в разделах «Гипотезы»/«Что проверить» с пометкой «модельные ответы, не доказательство».
