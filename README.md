# Стратег Фабрики продуктов

**Ничего не настраивайте. Откройте эту папку в Cursor, Claude Code, Codex или GigaCode и напишите в чат:**
> Новый проект: <ваш запрос или путь к файлу с брифом>

или, чтобы посмотреть готовый пример:
> Продолжи проект demo-family

Готовый результат демо-прогона: [`projects/demo-family/deliverables/STRATEGY.md`](projects/demo-family/deliverables/STRATEGY.md).
Там продуктовая и коммуникационная стратегии по брифу МегаФона «Связь для близких и собственных устройств», план проверки и таблица «откуда эти числа».

---

## Что это

Агент — это папка с инструкциями (`AGENTS.md`, навыки, роли), базой методических знаний (`kb/`) и CLI-инструментом `st.py`. «Мозг» — модель вашей IDE. Агент ведёт руководителя цифрового продукта по шагам:

```
постановка → сбор → диагноз → варианты → стратегия → план проверки → сборка → сопровождение
     ✋                            ✋                                      ✋        (пересмотр при новых данных)
```

✋ — точки, где решает человек: подтвердить постановку, выбрать направление, принять результат.

На выходе:
1. **Проверяемая картина ситуации:** что известно, откуда (источник и цитата), чего не знаем и почему.
2. **Не меньше трёх содержательно разных вариантов**, включая «оставить как есть» и «закрыть направление», у каждого — сильнейшее возражение.
3. **Согласованные продуктовая и коммуникационная стратегии** с планом проверки: метрика с числителем и знаменателем, база сравнения, выборка, срок, нежелательные последствия.
4. **Сопровождение после решения:** записи решений с основаниями, обязательства с ролями и сроками, триггеры пересмотра, пересчёт выводов при новых данных («было → стало»).

## Чем отличается от обычного чата

| Обычный чат | Этот агент |
|---|---|
| Числа в тексте не проверяются | Каждое число в документах имеет якорь `[F12]`, `[K03]`. Числа рядом с расчётом сверяются кодом с его результатом |
| «Факт» может быть выдуман | Факт регистрируется, только если его цитата найдена в сохранённом снимке источника |
| Синтетические «интервью» выглядят как данные | Модельные ответы `[Y]` могут поддерживать только гипотезы и не могут содержать процентов |
| После перерыва — всё заново | `python st.py resume`: стадия, что ждём от человека, прерванное, новые данные, стоимость |
| Решение «переписывается» задним числом | Принятое решение заморожено; изменение — только новым решением со ссылкой на прежнее |
| Новые данные — новый чат | `python st.py impact` находит затронутые выводы, пересчитывает расчёты, показывает «было → стало» |

## Установка

Нужен только **Python 3.10+**: зависимостей и ключей нет. Чтобы читать PDF, можно поставить `pip install pypdf` — это необязательно.

```bash
git clone <repo> && cd strateg
python st.py --project demo-family resume     # Windows: py st.py --project demo-family resume
python -m unittest discover -s tests          # 32 теста (unit, сквозные, регрессии по ревью), 1–2 минуты
```

Проверено на Windows 11 и Python 3.13 в OpenCode: тесты, `validate`, `check all` демо-проекта и сценарий новых данных проходят. Подробности — [`docs/VERIFICATION.md`](docs/VERIFICATION.md).

Интернет нужен только для загрузки страниц с разрешённых доменов (`config/allowlist.json`). Платные сервисы не нужны. Опционально можно включить Jev (TypeSafe AI) для узких проверок по рубрике: ключ задаётся в переменной окружения (см. `.env.example`), без ключа всё работает.

### По средам

| Среда | Что читает | Что сделать |
|---|---|---|
| **Claude Code** | `CLAUDE.md` → `AGENTS.md`, `.claude/skills`, `.claude/agents`, хуки | Ничего. При старте хук покажет сводку проекта. На Windows один раз: `py st.py sync --python py` |
| **Cursor** | `AGENTS.md`, `.cursor/rules`, `.agents/skills`, `.claude/agents` | Ничего. Разрешите автозапуск команд `python st.py` (Settings → Agent → Auto-run, allowlist) |
| **Codex CLI** | `AGENTS.md`, `.agents/skills`, `.codex/agents` | Ничего |
| **GigaCode** | `GIGACODE.md` → `AGENTS.md`, `.gigacode/skills` | Если `@`-импорт не сработал, первой фразой напишите «Прочитай AGENTS.md и следуй ему» |
| **Другие (Kodik, Copilot, OpenCode)** | `AGENTS.md` | Первой фразой: «Прочитай AGENTS.md и следуй ему» |

Адаптеры генерируются из одного источника командой `python st.py sync`; `python st.py validate` проверяет, что они актуальны, а секретов в репозитории нет.

## Как пользоваться

| Вы пишете | Агент делает |
|---|---|
| «Новый проект: …» / файл с брифом | `init --from`, постановка, не больше 3 вопросов |
| «продолжи» | `resume` и дальше с того же места, без повторов |
| «стоп» | останавливается и показывает `status` |
| «уточняю: …» | правит постановку, при необходимости возвращает стадию |
| «исправь F12: …», «отзови S14» | исправление в реестре → `impact` → переписывает затронутое |
| «откуда это число?» | `python st.py why K03` — цепочка до источника и цитаты |
| «новые данные» (файл в `materials/inbox/`) | пересмотр: что изменилось, что подтвердилось |
| «что решать сейчас?» | `decide due`: сроки, просрочки, сработавшие триггеры |
| «сколько стоило?» | `report run`: время, токены, деньги, минуты человека по стадиям |

Ход работы всегда виден в `projects/<проект>/PROGRESS.md`.

## Структура

```
AGENTS.md              регламент агента (единый источник правды для всех IDE)
.agents/skills/        10 навыков: intake, resume, collect, research, options, strategy,
                       validation-plan, review, after-decision, interviews (опция)
agent/roles/           субагенты: critic (сильная модель), source-reader (дешёвая), respondent (средняя)
agent/rubrics/         рубрика критика; узкие проверки для Jev (опция)
agent/templates/       шаблоны постановки, документов, согласия на интервью
kb/                    методические знания: постановка, доказательства, стратегия, коммуникации,
                       эксперименты, сопровождение решений, UX и данные (с источниками)
config/                allowlist доменов, бюджет, цены моделей, маршрутизация
tools/strateg/         код CLI (только стандартная библиотека Python)
projects/<slug>/       материалы и состояние конкретной задачи (отдельно от знаний и инструкций)
  materials/           файлы пользователя  ·  evidence/  снимки источников и реестр утверждений
  analysis/            расчёты K*.json → K*.out.json  ·  decisions/  решения и обязательства
  state/               task.json, журнал операций, стоимость  ·  deliverables/  документы
tests/                 unit и сквозные тесты (фикстура не из телекома)
docs/                  описание решения для жюри
```

Четыре вида знаний разделены папками и правами записи: постоянные инструкции (`AGENTS.md`, `agent/`, `.agents/`), методические знания (`kb/`), материалы проекта (`projects/*/materials`, `evidence/raw`) и состояние задачи (`projects/*/state`, пишет только `st.py`).

## Безопасность и данные

- Только открытые источники и материалы пользователя. Загрузка из сети — только с доменов из allowlist (проверяет код, а не модель).
- Снимки источников обёрнуты маркерами `<<<UNTRUSTED …>>>`. Текст вида «игнорируй инструкции» помечается и показывается пользователю, но не выполняется.
- Хуки Claude Code запрещают правку инструкций и запись в реестры в обход CLI. Но безопасность на хуках не держится: те же правила проверяет код.
- Ключей в репозитории нет (`validate` ищет их). Реальные интервью — только с согласием (`agent/templates/consent.md`) и без персональных данных.
