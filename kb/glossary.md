# Общий глоссарий (синонимы для поиска)

Формат: `- слово = синоним = синоним — пояснение`. Ложные синонимы — разные единицы, их нельзя смешивать.

## Синонимы
- отток = выбытие = churn = уход
- удержание = retention = сохранение
- выручка = доход = revenue
- прибыль = маржа = валовая прибыль
- клиент = абонент = пользователь
- воронка = конверсия = funnel
- пилот = эксперимент = тест
- допущение = предположение = assumption
- возражение = риск = контраргумент
- согласие = разрешение = consent

## Ложные синонимы (разные единицы)
- группа ≠ домохозяйство ≠ клиент ≠ номер ≠ SIM
- «в группе» ≠ «оплачивает» ≠ «активен»
- п.п. (абсолютная разница) ≠ % (относительная разница)
- подключение ≠ первое использование ≠ регулярное использование
