# Демо-проект: связь для близких

Этот проект показывает полный пример работы «Стратега Фабрики продуктов» над учебным брифом для цифрового оператора.

## Что было на входе

- `materials/brief.pdf` — учебный бриф с бизнес-целями, исходными числами и ограничениями.
- `materials/web/` — сохранённые материалы с открытых страниц операторов; они дают контекст альтернатив, но не доказывают частоту использования функций.
- В `brief.md` агент сформулировал вопрос, получателей результата, сроки решений и пробелы в данных.

В проекте нет клиентских баз и реальных интервью. Указанные в брифе бизнес-показатели — учебные; выводы о поведении клиентов помечены как факты из материалов, допущения или гипотезы.

## Итог для чтения

1. [`deliverables/STRATEGY-reader.md`](deliverables/STRATEGY-reader.md) — полный итоговый документ в читаемом виде.
2. [`deliverables/summary.md`](deliverables/summary.md) — краткое резюме для руководителя.
3. [`deliverables/product_strategy.md`](deliverables/product_strategy.md) — аудитория, задача, предложение, экономика и отказы.
4. [`deliverables/comms_strategy.md`](deliverables/comms_strategy.md) — барьер, сообщение, обещание и подтверждение функцией.
5. [`deliverables/validation_plan.md`](deliverables/validation_plan.md) — метрики, сравнение, срок и правила остановки.

## Вывод и выбор человека

Агент рекомендовал ограниченный пилот уведомления организатору семейной группы, если у участника заканчивается интернет. Уведомление ведёт к уже существующей операции добавления интернета и отправляется только при согласии участника. Человек выбрал пилот, затем принял итог; основания и обязательства связаны с решением в `deliverables/STRATEGY.md` и материалах сопровождения.

Документ честно отмечает, что эта инициатива не закрывает весь заданный разрыв прибыли. Масштабирование не предлагается без проверки операционных условий и последующего наблюдения за полезным результатом.

## Как проверить

Из корня репозитория:

```powershell
py st.py --project demo-family resume
py st.py --project demo-family check all
py st.py why K45
```

Сценарий новых данных работает на копии и не меняет этот проект:

```powershell
py eval/scenarios/new_data_q1.py
```

Сценарий показывает пересчёт затронутых выводов и перевод решения на пересмотр, а не его переписывание.
