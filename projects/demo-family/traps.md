# Ловушки задачи (чек-лист критика)

- [ ] Сигнал принят за причину (молчание близкого ≠ кончился интернет; связь оплачена ≠ устройство включено)
- [ ] Смешаны единицы: домохозяйство / группа / номер / SIM / человек; доля охвата не от 100 тыс. / 40 тыс.
- [ ] Активация посчитана не от всех созданных групп (знаменатель включает группы без ответа на приглашение)
- [ ] Инициативе приписаны все подключения года (нет сравнения с прогнозом «без изменений» 8 000)
- [ ] Двойной счёт канала (показ в приложении + обращение в поддержку)
- [ ] п.п. и % перепутаны (12 % → 9 % = −3 п.п. = −25 %)
- [ ] Рандомизация по номеру, а не по семье (общий пакет связывает участников)
- [ ] Анализ только откликнувшихся вместо всех назначенных (ITT)
- [ ] Перебои за неделю выданы за оплаченные месяцы за год
- [ ] Прибыль: месяцы вне планового года, двойной вычет затрат, разработка смешана с прямыми расходами
- [ ] Обещание без функции; доступ к начислениям «по умолчанию» при согласии только на остаток
- [ ] Отзыв согласия не прекращает показ сведений; повторное нажатие даёт второе списание/вычет
- [ ] Синтетические ответы использованы как доказательство спроса
- [ ] Недостижимая цель скрыта вместо «разрыв · цена · решение»
