# Комплект для отправки

## Файлы и разделы

- **ИИ-папка агента:** весь репозиторий `strateg-fabriki-produktov` на GitHub. Запуск и устройство описаны в корневом `README.md`.
- **Демонстрационный проект:** [`projects/demo-family/`](../projects/demo-family/), краткий указатель — [`README.md`](../projects/demo-family/README.md). Внутри есть учебный входной бриф, сохранённые открытые материалы, исходы исследования, продуктовая и коммуникационная стратегии и план проверки.
- **Видео:** русскоязычный ролик создаётся командой ниже. Для заявки загрузите полученный MP4 в облако или видеохостинг и вставьте ссылку.
- **Описание:** [`STRATEGY-DESCRIPTION.pdf`](STRATEGY-DESCRIPTION.pdf), также доступен исходник [`DESCRIPTION.md`](DESCRIPTION.md).

## Сборка видео

На Windows при наличии Python, Pillow, OpenCV, pywin32, русской речи SAPI и ffmpeg:

```powershell
py docs/build_demo_video.py --output "$env:USERPROFILE\Desktop\strateg-final-demo-narrated.mp4"
```

Ролик собирается из проектных документов и скриншотов; основной экран не записывается. Он показывает постановку, источники и доказательства, продолжение после перерыва, варианты, обе стратегии, план проверки и пересмотр после новых данных. Это не сквозной сеанс в Cursor или GigaCode; среду IDE нужно проверить отдельно.

## Перед отправкой

1. Загрузить архив или ссылку на GitHub, демонстрационный проект, MP4 и PDF в облачную папку.
2. Включить для материалов доступ «всем, у кого есть ссылка».
3. Открыть каждую ссылку в приватном окне и убедиться, что она доступна без входа.
4. Вставить ссылки в заявку. После дедлайна файлы по этим ссылкам не заменять.
