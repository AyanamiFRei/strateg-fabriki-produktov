# Сценарий видео (до 10 минут)

Готовность: демо-проект `projects/demo-family` уже пройден до стадии «Сопровождение». Для записи сделайте копию (`py -c "import shutil; shutil.copytree('projects/demo-family','projects/demo-video')"` на Windows; `cp -r projects/demo-family projects/demo-video` на Linux/macOS) или начните новый проект из того же брифа. Команды на Windows — `py st.py …`.

Перед записью (2 минуты):

```bash
py -m unittest discover -s tests     # 32 теста, OK
py st.py validate                    # 0 ошибок
py st.py --project demo-family check all   # 0 нарушений
```

Сценарий «пришли новые данные» запускается кроссплатформенно: `py eval/scenarios/new_data_q1.py` (Windows) или `python3 eval/scenarios/new_data_q1.py`. Он создаёт копию `projects/demo-q1-data` и не меняет демо-проект.
