# Проверка репозитория: что и где запускалось

Дата: 2026-11-22. Среда: Windows 11, Python 3.13.7, OpenCode (агентный режим). Репозиторий открыт как рабочая папка; команды выполнялись из корня.

## Итог

| Проверка | Команда | Результат |
|---|---|---|
| Адаптеры IDE и секреты | `py st.py validate` | `ошибок 0, предупреждений 0`; 39 файлов адаптеров актуальны |
| Демо-проект | `py st.py --project demo-family check all` | `Жёстких нарушений: 0; предупреждений: 0` |
| Тесты | `py -m unittest discover -s tests` | `Ran 32 tests ... OK` (75–115 с на Windows) |
| Возобновление | `py st.py --project demo-family resume` | стадия «Сопровождение», ворота, стоимость, следующий шаг |
| Новые данные | `py eval/scenarios/new_data_q1.py` | новый источник S07, A04 v3, 16 расчётов «было → стало», D01 → revisiting, 36 устаревших чисел поймано `check all` |
| Запуск по README | `py st.py --project demo-family resume` | работает и до, и после команды (`--project`) |
| Кириллица в путях | тест `TestUnicodePaths` | проходит: путь `Мои проекты/стратег тест`, cp1251 |
| PDF-описание | `py docs/build_screenshots.py`, `py docs/build_description_pdf.py` | 7 изображений из реального вывода команд; `docs/STRATEGY-DESCRIPTION.pdf` — 10 страниц A4, текст и рисунки на месте, номера страниц |

## Что это доказывает

- Репозиторий запускается на чистой Windows без зависимостей: нужен только Python 3.10+.
- Демо-проект проходит все жёсткие инварианты; числа в документах сверены с расчётами.
- Сквозной путь «новые данные → пересчёт → пересмотр решения» работает на копии проекта и не портит демо.
- Тесты покрывают критические находки ревью: подделку снимка, связи с отклонёнными строками, синтетику через промежуточный вывод, ворота человека, `--project`, DoS в арифметике, повреждённые строки.

## Что не запускалось

- **Cursor, GigaCode, Claude Code, Codex** — не установлены в этой среде. Адаптеры для них генерируются и проверяются `validate`, но сквозной прогон в каждой IDE остаётся за командой (чек-лист — `docs/VIDEO.md`).
- **Видео-демонстрация** — собрана как русскоязычный ролик из материалов проекта и скриншотов реальных CLI-команд: `docs/build_demo_video.py`. Это не запись живого сеанса в IDE; ограничения проверки Cursor и GigaCode остаются.
- **PDF-описание** — `docs/STRATEGY-DESCRIPTION.pdf` (10 страниц, скриншоты и схема архитектуры).
- **Реальные интервью** — не проводились; модельные ответы помечены как синтетика `[Y]` и не используются как доказательство.

## Как повторить

```bash
py st.py validate
py st.py --project demo-family check all
py -m unittest discover -s tests
py eval/scenarios/new_data_q1.py
py docs/build_screenshots.py          # скриншоты из реального вывода (Pillow)
py docs/build_description_pdf.py      # PDF через Chrome headless + PyMuPDF для номеров страниц
```

Ожидаемо: первые три команды — код 0; сценарий новых данных завершается кодом 0, а `check all` внутри него намеренно возвращает 2 и показывает устаревшие числа — это демонстрация того, что проверка работает.
