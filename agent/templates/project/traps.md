# Ловушки задачи (чек-лист критика)

<!-- Заполняется на постановке под конкретную задачу. Базовые: -->
- [ ] Сигнал принят за причину (рост/падение объяснён без проверки альтернатив)
- [ ] Смешаны единицы (группа / номер / клиент / домохозяйство) или периоды
- [ ] Доли посчитаны от разных знаменателей (воронка)
- [ ] Сравнение без базы: эффект без контрольной группы или обычного обслуживания
- [ ] Абсолютная и относительная разница перепутаны (п.п. vs %)
- [ ] Рандомизация не по той единице (люди внутри группы влияют друг на друга)
- [ ] Обещание в коммуникациях без функции в продукте
- [ ] Синтетические ответы использованы как доказательство спроса
- [ ] Не учтён отзыв согласия / выход участника / повтор операции
